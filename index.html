The challenge

The Friction of Family Coordination

Family organization is fragmented across apps that feel like a chore, especially for non-English speakers. Too much typing and manual navigation lead to missed reminders and forgotten grocery items.

For Spanish-speaking families, tools that default to English add even more friction and cognitive load.

The solution

Organize the household through conversation.

RememberMe centralizes family organization through a Spanish-language voice assistant. Users manage shared shopping lists and reminders entirely through natural speech.

04 / The Hardest Part

The Hardest Part

Family organization is often fragmented across multiple apps that feel like a chore to use, especially for non-English speakers. Existing tools require too much typing and manual navigation, which leads to missed reminders and forgotten grocery items.

How Raúl overcame it

  1. 1

    Implemented end-to-end encrypted Web Push notifications within Supabase Edge Functions under strict import constraints.

  2. 2

    Designed a secure invitation system using PostgreSQL RLS and SECURITY DEFINER functions to prevent privilege escalation.

  3. 3

    Debugged WebSocket handshakes to ensure JWT values were correctly passed to the AI agent for authenticated actions.

How it was built

RememberMe is a Progressive Web App (PWA) built with React, TypeScript, and Vite. It uses a pnpm monorepo structure with an Express API and a Supabase backend. Authentication and data security are handled through PostgreSQL Row-Level Security (RLS) policies. For the voice interface, I integrated the ElevenLabs Conversational AI SDK, creating a custom draggable widget. JWT and timezone data pass through WebSocket dynamic variables to enable secure, authenticated tool calls.
